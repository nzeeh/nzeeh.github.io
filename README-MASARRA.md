# مسرّة اليمن — Android Alpha 0.2.0

نسخة احترافية أولية لمنصة خدمات الأعراس اليمنية.

## أبرز ما أضيف في 0.2.0

- إنشاء حسابين منفصلين: طالب خدمة أو مقدم خدمة.
- تصنيف مقدم الخدمة إلى فنان/منشد منفرد أو فرقة فنية/شعبية.
- نموذج تسجيل متغير حسب نوع الحساب.
- واجهة العروس والعريس والعروسين بألوان وترتيب خدمات مختلف.
- لوحة احترافية لمقدم الخدمة تشمل الطلبات، المواعيد، المقاطع، الملف والتوثيق.
- رفع صور/فيديوهات واختيار وثيقة الهوية محليًا من الهاتف.
- حفظ الحسابات وكلمات المرور المشفرة والحجوزات محليًا على الجهاز.
- مشاركة الملف عبر تطبيقات الهاتف.
- حجز تجريبي، مفضلة، خطة عرس، ميزانية ومجلس عائلة.

## ملاحظات تشغيلية

هذه نسخة Alpha للعرض والاختبار. لا يوجد خادم مركزي أو دفع حقيقي أو رسائل OTP أو مراجعة إدارية حقيقية في هذا الإصدار. الربط الفعلي يتطلب Backend آمنًا، تخزينًا مشفرًا، لوحة إدارة واتفاقات مع مزودي الدفع.
