# مسرّة اليمن — نموذج أندرويد أولي

نسخة تجريبية عربية تعمل دون إنترنت لعرض مفهوم منصة الأعراس اليمنية.

## الوظائف الحالية

- اختيار مسار العروس أو العريس أو العروسين مع هوية لونية متغيرة.
- عرض فنانين وفرق وفنون شعبية حسب المحافظة.
- تشغيل مقتطف صوتي تجريبي أصلي مولد داخل التطبيق.
- نموذج حجز محلي واختيار الباقة والمحافظة والمحفظة الإلكترونية.
- كتالوج ملابس وإكسسوارات للبيع أو الإيجار.
- بصمة الفرح، مجلس العائلة، الدعوة والرفد، ونقاط مسرّة.

## تنبيه

هذه نسخة Alpha لإثبات الفكرة. لا تنفذ مدفوعات حقيقية، ولا ترسل الحجوزات إلى مقدم خدمة، ولا تحتوي بعد على خادم مركزي أو حسابات موثقة. أي ربط مالي فعلي يجب أن يتم لاحقًا بعقود وواجهات رسمية مع المحافظ المرخصة.
