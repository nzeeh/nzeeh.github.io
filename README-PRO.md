# مسرّة اليمن — Pro Preview 0.2.0

تحديث: الأربعاء 9 سبتمبر 2026.

هذا الفرع مستقل عن الموقع العقاري وعن النسخة القديمة. يحتوي مصدر النسخة الجديدة المضغوط في `.masarra-pro-source/part*.b64`، وخط بناء Android وiOS في `.github/workflows/build-masarra-pro.yml`.

## استعادة المصدر

```sh
cat .masarra-pro-source/part*.b64 | base64 -d > masarra-pro-src.tar.xz
echo '401bc5d9c353cd5fc37bda462167a31a85b930f813d3df791b0b167cce897090  masarra-pro-src.tar.xz' | sha256sum -c -
tar -xJf masarra-pro-src.tar.xz
cd Masarra-Pro-v0.2.0
npm install
npm test
```

اقرأ `README_AR.md` داخل المصدر لتعليمات المشاريع الأصلية والخادم التجريبي. لا تضف مفاتيح دفع أو توقيع أو بيانات مستخدمين إلى المستودع.

## المنفذ

- حساب طالب خدمة أو مقدم خدمة؛ فنان، فرقة موسيقية، فن شعبي، إنشاد، ملابس، إكسسوارات وخدمات مساندة.
- هوية العروس/العريس/العروسين مستقلة عن دور الحساب، بألوان شبابية وواجهة عربية RTL.
- 22 اختيارًا إداريًا لليمن، أمانة العاصمة وصنعاء منفصلتان، بما فيها سقطرى.
- بحث وتصفية ومقارنة ومفضلة وباقة متعددة الخدمات وحجز تجريبي وإلغاء.
- لوحة مقدم الخدمة، عروض ومسودات ومواعيد، ووسائط محلية قصيرة مع إقرار حقوقها.
- خطة وميزانية ومجلس عائلة محلي، مشاركة دعوة نصية، تصدير وحذف الحساب.
- API تجريبي منفصل، أدوار معزولة، أسعار يحسبها الخادم، ومنع تعارض الحجوزات المقبولة.
